# AI 售后工单辅助台

面向电商商家的售后问答辅助工具：把客户问题归类，给出**答复建议 + 规则依据**，并明确标出**什么时候不能让 AI 自己回答**。

> 这是个人项目，用于演练与求职展示。规则为模拟规则，**不代表任何真实商家的售后制度**，未经真实商家验证。

## 现在是什么状态

- 版本：V1（规则版，**尚未接入大模型**）
- 规则库：5 类 × 15 条 + 12 个转人工触发词
- 测试：12 条设计用例 **12/12 通过**；6 条换说法用例 **0/6 命中**（详见 `tests/BADCASES.md`）
- 界面：Streamlit 页面（客户消息 + 商品类型 + 订单情况 → 分类、建议、依据、待确认信息）

## 怎么运行

**方式一（推荐）**：双击 `run.bat`，浏览器自动打开。

**方式二（PyCharm）**：打开本项目，在终端执行
```
python -m streamlit run app.py
```

**方式三（命令行，最快）**：
```
python main.py "我买的东西还没发货，想退款"
```

## 产品边界（这是重点）

输出只有三类，没有第四类：

1. **规则明确 + 信息齐全** → 给答复建议与依据
2. **关键信息缺失** → 提示补充，不硬答
3. **赔付 / 投诉 / 例外承诺 / 规则未覆盖** → 转人工，AI 不独立担责

设计意图：宁可少答，不可乱答。测试里「转人工」不算失败，**错误答复才算**。

## 已知问题

1. **关键词匹配对换说法没有鲁棒性**：12 条设计用例全过，但 6 句日常说法全落转人工（见 `tests/BADCASES.md`）。
2. 规则未接入模型，无法处理否定、多意图混合、长对话上下文。
3. 没有用户测试、没有部署、没有真实客服对话验证。

## 下一步

1. 接大模型做意图分类（模型只分类与抽取信息，答复仍由规则给出，避免模型编造规则）
2. 规则未命中时先主动追问一句，而不是直接转人工
3. 用 20 句真实客服说法测命中率，目标 ≥ 70% 且错误答复 = 0
